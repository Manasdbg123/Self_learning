# AI Engineering Knowledge Platform

Welcome to the AI Engineering Knowledge Platform. This is a personal AI-powered engineering knowledge system designed for deep technical learning, interview preparation, and research.

## Project Structure

- `frontend/`: Next.js web application
- `backend/`: Java Spring Boot backend
- `docker/`: Docker Compose for infrastructure (PostgreSQL, Redis, Kafka, Vector DB)
- `docs/`: Architecture and API documentation

## Tech Stack
- Frontend: Next.js, TailwindCSS, shadcn/ui
- Backend: Java 21, Spring Boot
- Storage: PostgreSQL, Redis, Qdrant/Milvus (Vector DB)
- Messaging: Apache Kafka

## Setup

Please refer to the setup instructions inside each directory once they are fully scaffolded.
